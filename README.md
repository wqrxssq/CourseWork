# RTB Analytics — Курсовая работа

Исследовательский проект на тему "Анализ и визуализация данных с использованием Yandex DataLens, на примере данных iPinYou"

## О проекте

В работе исследуются статистические закономерности и ключевые показатели эффективности рекламных кампаний: CPM, CTR, CVR, eCPC, eCPA на основе датасета **IPinYou**. При помощи Yandex Datalens визуализируется RTB-воронка (ставки → показы → клики → конверсии) в разрезе типа устройства, времени, параметров рекламного слота, рекламодателя, а также создается интерактивный дашборд. Для обеспечения доступности аналитических логов используется СУБД ClickHouse.

**Стек:** Yandex DataLens - ClickHouse - Python

## Дашборд

Интерактивный дашборд: [datalens.yandex/ekzq1ggrjl24y](https://datalens.yandex/ekzq1ggrjl24y)

Так как ClickHouse разворачивается локально и порт прокидывается через ngrok, дашборд может быть доступен с перебоями.

## Структура репозитория

```
overleaf/           # LaTeX-исходники письменного отчёта
src/
  schemas/          # DDL-схемы таблиц ClickHouse для всех логов
  data_preparation/ # Python-скрипты: валидация и обогащение признаков
  datalens/         # Конфигурации чартов DataLens (RTB-воронка)
main.pdf            # Скомпилированный отчёт (PDF)
```
