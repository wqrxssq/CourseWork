\section{Проектирование и разработка макета интерактивного дашборда}
\label{sec:dashboard_design}

\subsection{Концепция и архитектура дашборда}
\label{subsec:dashboard_architecture}

При проектировании архитектуры дашборда учитывались возможные потребности трех основных групп потенциальных пользователей. Это позволило определить, какие именно данные необходимо размещать на дашборде, а также принципы их разделения и группировки. Выделены следующие основные группы пользователей:

\begin{itemize}
    \item \textbf{Менеджеры проектов, руководители, представители рекламных площадок и рекламодатели.} Данной группе пользователей необходим верхнеуровневый срез данных для оценки общей эффективности рекламных кампаний, контроля расходования бюджета и достижения бизнес-целей (KPI). Их основной фокус направлен на финансовые показатели (CPM, eCPA, eCPC) и метрики конверсии (CTR, CVR), что позволяет принимать управленческие решения об оптимизации рекламных стратегий.
    \item \textbf{Дата-инженеры и дата-аналитики.} Этим специалистам требуется глубокое понимание структуры данных, распределений признаков и наличия аномалий. Им необходимы инструменты для разведочного анализа данных, выявления скрытых закономерностей, подготовки признаков для последующего построения моделей машинного обучения.
    \item \textbf{Разработчики проекта.} Для данной группы важен мониторинг технического состояния системы торгов (win ratio, объемы входящего трафика по типам событий) и анализ влияния различных технических факторов (платформа, браузер, формат слота) на итоговые метрики. Это необходимо для отладки алгоритмов назначения ставок (bidding) и оптимизации высоконагруженных компонентов системы.
\end{itemize}

Для удовлетворения потребностей всех перечисленных групп дашборд концептуально разделен на три независимые, но логически связанные вкладки, каждая из которых решает свой класс задач.

\subsection{Эффективность RTB-рекламы}
\label{subsec:dashboard_metrics}

Целью данной вкладки является предоставление сводной информации о ключевых показателях эффективности рекламных кампаний для оперативного мониторинга бизнес-результатов. Вкладка ориентирована преимущественно на менеджеров и рекламодателей.

В датасете данные метрики реализуются через вычисляемые поля на основе агрегации базовых событий: суммирование стоимости выигранных ставок для расчета затрат, подсчет количества событий показов (\texttt{imp}), кликов (\texttt{clk}) и конверсий (\texttt{conv}).

Для фильтрации и детализации данных предусмотрены следующие селекторы:
\begin{itemize}
    \item \textbf{Диапазон дат} — для анализа динамики показателей за выбранный период.
    \item \textbf{Рекламодатель} — для оценки эффективности кампаний конкретного клиента.
    \item \textbf{Платформа (ОС) и Браузер} — для сегментации аудитории по техническим характеристикам.
\end{itemize}

На вкладке предполагается размещение следующих визуализаций:
\begin{itemize}
    \item Индикаторы с текущими значениями ключевых метрик и спарклайнами для отображения краткосрочных трендов.
    \item Линейный график динамики основных KPI с течением времени.
    \item Столбчатая диаграмма распределения бюджета и количества кликов/конверсий по топ-5 рекламодателям.
    \item Таблица с детализацией метрик по рекламным кампаниям.
\end{itemize}

\subsection{Разведочный анализ данных (EDA)}
\label{subsec:dashboard_eda}

Цель данной вкладки — предоставить аналитикам инструменты для глубокого погружения в структуру собранного датасета, выявления распределений, паттернов и возможных аномалий в трафике.

Для реализации задач EDA необходимы следующие визуализации:
\begin{itemize}
    \item \textbf{RTB-воронка:} Bid $\rightarrow$ Impression $\rightarrow$ Click $\rightarrow$ Conversion. Позволяет визуально оценить потери трафика на каждом этапе взаимодействия пользователя с рекламой.
    \item \textbf{Гистограммы распределения} событий по времени суток и дням недели для выявления сезонности и пиков активности пользователей.
    \item \textbf{Круговые или кольцевые диаграммы} долей трафика по платформам (ОС) и браузерам.
    \item \textbf{Таблица или график распределения} трафика по рекламной бирже (Ad Exchange)/региону/городу.
    \item \textbf{График относительного спреда ставок:} визуализация отношения разности между максимальной и минимальной ценой ставки к их среднему значению в разрезе временных интервалов или сегментов аудитории. Позволяет оценить волатильность аукционных цен и выявить сегменты с нестабильной конкурентной средой.
\end{itemize}
Данные чарты помогут выявить такие паттерны, как преобладание мобильного трафика в определенные часы, аномально низкий трафик на специфических доменах, непропорционально высокую стоимость клика в отдельных регионах, а также сегменты с высокой волатильностью аукционных цен, диагностируемой через относительный спред ставок.

\subsection{Многофакторный анализ KPI рекламных кампаний}
\label{subsec:dashboard_kpi_factors}

Цель данного раздела дашборда — предоставить гибкий инструмент для исследования влияния различных технических и контекстных факторов на итоговую эффективность рекламы. Это позволяет находить неочевидные инсайты для оптимизации таргетинга, корректировки ставок и улучшения пользовательского опыта.

Главной особенностью данной вкладки является интерактивность: с помощью специального селектора, реализованного через механизм параметров, пользователь дашборда может динамически выбирать целевую метрику для анализа (CTR, CVR, CPM, eCPC или eCPA). Все графики на вкладке автоматически перестраиваются для отображения распределения выбранной метрики в различных срезах.

Для всестороннего анализа на вкладке представлены следующие визуализации:
\begin{itemize}
    \item \textbf{Влияние места размещения:} столбчатая диаграмма, показывающая, как выбранная метрика зависит от расположения рекламного блока на странице.
    \item \textbf{Влияние платформы и браузера:} линейчатая диаграмма, показывающая, как выбранная метрика зависит от платформы/браузера.
    \item \textbf{Влияние типа рекламы:} столбчатая диаграмма, демонстрирующая разницу в эффективности между всплывающими (popup) и фиксированными форматами рекламы.
    \item \textbf{Влияние времени:} линейный график, отображающий динамику метрики в зависимости от часа дня/дня недели, что критично для настройки временного таргетинга.
    \item \textbf{Влияние размера креатива:} диаграмма рассеяния (Scatter plot) или ящиковая диаграмма (Box plot), позволяющая оценить, какие габариты баннеров (ширина и высота) приносят наилучший результат.
\end{itemize}
